## [1.0.0] - 2025-04-27

### Добавлено

#### Модуль SIRPetri.jl
- Реализована функция `build_sir_network(β, γ)` для построения размеченной сети Петри с двумя переходами:
  - `infection`: S + I → I + I (скорость β)
  - `recovery`: I → R (скорость γ)
- Реализована функция `simulate_deterministic()` для детерминированного моделирования (решение ОДУ методом Tsit5)
- Реализована функция `simulate_stochastic()` для стохастического моделирования (прямой алгоритм Гиллеспи)
- Реализована функция `sir_ode()` для формирования правой части системы ОДУ
- Реализована функция `plot_sir()` для визуализации динамики S, I, R
- Реализована функция `to_graphviz_sir()` для визуализации сети Петри в формате Graphviz

#### Скрипты
- `scripts/sirpetri_run.jl` — базовый прогон модели с параметрами β=0.3, γ=0.1
  - Детерминированная симуляция → `data/sir_det.csv`, `plots/sir_det_dynamics.png`
  - Стохастическая симуляция → `data/sir_stoch.csv`, `plots/sir_stoch_dynamics.png`
- `scripts/sirpetri_scan_parameters.jl` — параметрическое сканирование коэффициента заражения β
  - Диапазон β = 0.1 : 0.05 : 0.8 (15 значений)
  - Сохранение результатов в `data/sir_scan.csv`
  - График зависимости пика I и финального R от β → `plots/sir_scan.png`
- `scripts/sirpetri_animate.jl` — анимация детерминированной динамики
  - Сохранение GIF-анимации → `plots/sir_animation.gif`
- `scripts/sirpetri_report.jl` — итоговый отчёт
  - Сравнение детерминированного и стохастического I(t) → `plots/comparison.png`
  - График чувствительности пика I от β → `plots/sensitivity.png`

#### Документация
- Литературное программирование: все скрипты преобразованы в формат Literate.jl
- Сгенерированы производные форматы:
  - Чистый код (`.jl`)
  - Jupyter Notebook (`.ipynb`)
  - Документация Quarto (`.qmd`)
